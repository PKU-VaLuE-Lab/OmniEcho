# README organization logos

The README uses the official Peking University, Qwen, and Tsinghua University
logos. Each is placed on a white background with consistent display dimensions.
Only whitespace, scaling, and canvas padding were adjusted; the marks retain
their original colors and proportions.

- `pku-logo.png`: [Peking University official website](https://www.pku.edu.cn/),
  [source image](https://www.pku.edu.cn/Uploads/Picture/2019/12/26/s5e04176fbbfa3.png).
- `qwen-logo.png`: [Qwen official website](https://qwen.ai/),
  [source image](https://img.alicdn.com/imgextra/i3/O1CN01JLF4IJ1yAv1ZE7bfQ_!!6000000006539-2-tps-180-48.png).
- `tsinghua-logo.png`: [Tsinghua University visual identity standards](https://vi.tsinghua.edu.cn/gk/xxbz/bzzh1.htm),
  [source image](https://vi.tsinghua.edu.cn/__local/E/87/55/EDE2CD6FC2310945BA206EC8242_9AA2B06D_18167.jpg).

The organization names and marks belong to their respective owners. These
trademarks are not relicensed under the benchmark data license.
